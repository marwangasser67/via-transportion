# Via — نظام إدارة وتتبع الرحلات والأسطول الذكي

## ملفات المشروع
- `index.html`: هيكل الصفحة.
- `styles.css`: جميع تنسيقات CSS، بما فيها تنسيقات Tailwind المضمّنة في الملف الأصلي.
- `app.js`: وظائف JavaScript.

## التشغيل
افتح `index.html` في المتصفح. اتصال الإنترنت مطلوب لتحميل Cairo/Poppins وFont Awesome وLeaflet والخرائط.

## الرفع إلى GitHub Pages
1. أنشئ مستودع GitHub وارفع الملفات الثلاثة وملف README.md إلى جذر المستودع.
2. من **Settings → Pages** اختر **Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/ (root)` ثم احفظ.
4. افتح الرابط الذي يظهر في صفحة Pages.

هذا تقسيم للملف المرفق إلى ملفات مصدر منفصلة، مع إبقاء المكتبات الخارجية عبر CDN.
